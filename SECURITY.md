# Security

Report a malicious or compromised listing privately through [GitHub private vulnerability reporting](https://github.com/sharafutdinovdi/awesome-bim-tools/security/advisories/new).
Include the listing name, its address and a short description of the concern.
Do not include executables, secrets or personal data.

Listings link to third-party software that this list does not audit.
Verify the source before downloading or installing any tool.
