# Contributing

Use the [suggestion form](https://github.com/sharafutdinovdi/awesome-bim-tools/issues/new?template=suggest-tool.yml) for new tools.
For the catalog format, submission instructions and correction checks, see [AGENTS.md](AGENTS.md).
Suggestions go through automatic checks for scope, valid public links and duplicates.
An acceptable entry describes a maintained BIM tool, points to a public page for that tool and states its function without promotional claims.
Suggestions that cannot be verified automatically require manual review.

Pull requests may only correct one existing `tools/<slug>.json` entry.
The files in `dist/`, the README tables and the logos are generated; do not edit them by hand.
Generated files are rebuilt after a correction is merged.
I review corrections manually and never merge them automatically.

To request a correction or removal, use the [listing change form](https://github.com/sharafutdinovdi/awesome-bim-tools/issues/new?template=change-or-remove.yml).
For removal requests, include a public source that shows you make the tool.
